Sources & method

The columns share a depth scale starting at each well’s ground surface. Each numbered band marks one recorded interval. Each colour separates a recorded interval. Matching numbers or colours across wells carry no geological meaning. The selected-depth line shows where to read each column. Hatching marks gaps within a log. The pale area below the final boundary marks its end. Different ground elevations and the distances between wells make these spot records unsuitable for tracing a continuous formation.

The first selection covers 18 Langley well tags. The Nova Scotia sample uses eight logs per community across six communities in Halifax County from the province’s 2020 public database. Both sources report intervals in feet. Metres use 0.3048 metres per foot.
